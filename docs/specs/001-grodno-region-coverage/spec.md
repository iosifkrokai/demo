# Spec 001 — Grodno Region Coverage

## Проблема

Пайплайн маршрутов сейчас опирается на ~76 мест только города Гродно. Для туриста
по Гродненской области (17 районов: Гродненский, Лидский, Новогрудский, Слонимский,
Волковысский, Сморгонский, Ошмянский, Островецкий, Ивьевский, Дятлововский,
Мостовский, Щучинский, Берестовицкий, Свислочский, Кореличский, Зельвенский,
Вороновский) данных нет, а значит маршрут «выходного дня по области» построить нельзя.

## Требования

### MUST
1. Схема `places` хранит для каждого места: `opening_hours` (текст, ru),
   `ticket_price` (текст, ru), `visit_minutes` (int, оценка), `district` (район),
   `town` (город/агрогородок), плюс уже существующие `fun_fact(s)`, `links`.
2. Датасет `data/places_region.csv` покрывает **все 17 районов области**, минимум
   3 знаковых места на район; для районов с топ-объектами (Мир, Новогрудок, Лида,
   Слоним, Сморгонь/Крево, Ошмяны/Гольшаны, Островец/Гервяты) — 4–8 мест.
3. У каждого места заполнены: name, category (таксономия из `agent/search.py`),
   district, town, lat, lon, blurb, fun_fact, opening_hours, ticket_price,
   visit_minutes, links (JSON), source_url.
4. Seed идемпотентен: повторный запуск обновляет, а не дублирует (ключ `source_url`).
5. API `/routes/generate` возвращает новые поля (`opening_hours`, `ticket_price`,
   `town`, `district`) в каждом `point`.
6. Агент работает без `OPENROUTER_API_KEY`: векторный поиск деградирует до
   keyword-поиска, `/health` честно показывает `llm=false`.
7. Bbox фильтра агента покрывает всю область (23.50–26.55, 52.85–54.10) —
   уже выполнено в `constants.GRODNO_BBOX` (`{south: 52.75, west: 23.35, north: 54.80, east: 27.00}`);
  места области не отбрасываются пайплайном.
8. Время работы/цены в датасете помечены как ориентировочные в README.

### SHOULD
9. Город Гродно остаётся покрытым scrape-источником (planetabelarus.by) +
   curated CSV; region-датасет его дополняет, а не заменяет.
10. Категории из region-датасета валидируются скриптом против таксономии агента.

### WON'T (здесь)
- Реальные брони/расписания, парсинг часов с сайтов музеев, фото.

## Критерии приёмки
- [ ] Миграция применена, `\d places` содержит новые колонки.
- [ ] В `places` ≥ 120 строк, ≥ 60 из `places_region.csv`, каждый район области
      представлен ≥ 3 местами (проверяется SQL-запросом из tasks.md).
- [ ] `POST /routes/generate` с запросом «замки и костёлы Новогрудка, 3 часа»
      возвращает маршрут с местами за пределами города Гродно.
- [ ] Без `OPENROUTER_API_KEY` агент отвечает 200 (keyword fallback), `/health`
      отдаёт `degraded`.
- [ ] В ответе API присутствуют `opening_hours` и `ticket_price` у точек, где
      они заполнены.
